# Optimizer System 前端设计审查与修改规划

## 一、项目概况

Optimizer System 是基于 Tauri 2 的桌面文本优化器，前端为零依赖纯 DOM 渲染（`main.js` 187KB 动态生成 HTML，`styles.css` 820 行承载全部视觉样式）。界面为中文优先的双语应用，核心功能包括文档树编辑、AI 续写/润色/压缩/扩写/批评、Patch 逐 hunk 审查、版本历史、多模型网关与费用洞察。

## 二、设计审查：11 处"AI 味"问题

| # | 问题 | 位置 | 严重度 |

| 7 | Georgia 衬线全局滥用 | 品牌标识/标题/编辑器/卡片/弹窗 | 中 |

## 三、设计方向：编辑极简主义

以「极简」设计库为约束源，从"温暖舒适模板"转向**克制的编辑极简主义**。核心原则：让层级、间距与字体承担设计，而非依赖装饰性渐变与阴影。

### 3.1 色彩系统 — 单色中性

| 语义 | 旧值 | 新值 | 说明 |
|------|------|------|------|
| 正文墨色 | `#25231f` | `#18181b` | 近黑冷灰 |
| 次要文字 | `#777268` | `#71717a` | 中性灰 |
| 细线边框 | `#d8d2c8` | `#e4e4e7` | 极淡灰 |
| 内容面 | `#fffdf8` | `#ffffff` | 纯白 |
| 次级面 | `#f6f2ea` | `#fafafa` | 冷灰白 |
| 强调色 | `#2f6b50` (绿) | `#18181b` (黑) | 黑色作为主操作色 |
| 强调浅底 | `#dce9df` | `#f4f4f5` | 浅灰底 |
| 成功 | `#275c45` 系 | `#16a34a` 系 | 保留语义但更鲜明 |
| 危险 | `#9b3f36` 系 | `#dc2626` 系 | 保留语义但更鲜明 |
| 警告 | `#9a601e` 系 | `#d97706` 系 | 保留语义但更鲜明 |

### 3.2 字体 — 双系统

- **UI 界面**（工具栏/侧栏/抽屉/按钮/标签）：`Inter, system-ui, "PingFang SC", sans-serif`
- **编辑器正文**（正在编辑的文档内容）：保留 `Georgia, "Songti SC", serif` — 写作工具中衬线正文是有意为之
- **代码/哈希/diff**：`ui-monospace, "Cascadia Mono", monospace`
- 最小字号提升至 11px，消除 9px 文字

### 3.3 圆角 — 仅 3 级

- `--radius-sm: 6px` — 药丸、标签、小芯片
- `--radius: 8px` — 卡片、输入框、按钮（默认）
- `--radius-lg: 12px` — 模态框、面板、编辑器纸面

### 3.4 阴影 — 克制分层

- 普通面：无边框无阴影，或 1px 细线
- 卡片：`0 1px 2px rgba(0,0,0,0.04)`（几乎不可见）
- 悬浮层（模态/弹出）：`0 8px 24px rgba(0,0,0,0.08)`
- 品牌标识移除辉光

### 3.5 移除 AI 交互特征

- 删除 `transform: translateY(-1px)` 悬停位移 → 改为背景色变化
- 删除 `backdrop-filter: blur()` → 改为纯色半透明遮罩
- 焦点环从 `#3b82f6` 蓝色 → `#18181b` 近黑色，与主色调一致
- 删除欢迎页所有渐变

### 3.6 间距 — 4px 基准

所有间距统一为 4px 倍数：4, 8, 12, 16, 20, 24, 32, 40, 48, 64

## 四、实施范围

| 文件 | 改动类型 | 说明 |
|------|----------|------|
| `apps/optimizer-desktop/src/styles.css` | 全量重写 | 820 行 → 全新设计令牌与样式 |
| `apps/optimizer-desktop/src/main.js` | 局部修改 | 仅 FPS 监视器 3 个硬编码颜色值 |
| `apps/optimizer-desktop/src/index.html` | 不变 | 结构由 JS 生成，无需改动 |

## 五、不变项

- 所有 CSS 类名保持不变（`main.js` 依赖）
- 所有 HTML 结构不变
- 响应式断点逻辑不变（1000px / 640px）
- 无障碍规则保留（`:focus-visible`、`prefers-reduced-motion`、`.optimizer-a11y-live`）
- 编辑器正文衬线字体保留（写作工具的核心体验）
