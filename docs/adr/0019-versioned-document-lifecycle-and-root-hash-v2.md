# ADR 0019：版本化章节生命周期与项目根哈希 v2

- 状态：Accepted
- 日期：2026-07-16
- 决策范围：章节重命名、排序、软归档、恢复与检查点一致性
- 取代：ADR 0012/0016 中“章节改名、移动、删除待实现”的阶段性限制

## 背景

章节创建和跨结构检查点恢复已经存在，但活动章节仍不能改名、调整顺序或安全删除。若把这些操作作为普通 SQL 更新，它们不会形成 Commit，也不能参与乐观并发和项目根哈希；若直接删除 Document，其 Block、历史版本和检查点恢复链都会失去稳定身份。

项目根哈希 v1 只绑定活动 Block 内容。即使章节标题或顺序已变化，只要正文未变，v1 仍会得到相同根哈希，无法准确表达结构状态。旧恢复算法也会拒绝快照与当前章节元数据不同的情况。

## 决策

1. 章节重命名、相邻上移/下移、软归档和恢复统一使用 `ApplyDocumentBatch`。命令必须绑定主分支 HEAD、项目 revision 和每个 Document 的 `expectedRevision`，全部元数据更新、ChangeSet、Commit、分支 HEAD 与项目 revision 在一个 `IMMEDIATE` 事务中完成。
2. 删除语义固定为软归档：设置 `document.deleted_at`，不删除 Document 或 Block。活动工作区、全文搜索、导出与 Context 只读取活动 Document；归档列表只返回安全元数据，不返回正文。
3. 一个项目至少保留一个活动 Document。活动 Document 不能引用已归档父节点，最终树必须无环，且同一父节点下的 `order_key` 唯一。
4. 排序操作为全部活动章节生成同一随机命名空间下的确定性顺序键，并先把受影响行暂存到事务内临时键，避免交换顺序时触发唯一约束。当前桌面 MVP 只开放顶层相邻移动，存储批处理保留未来树形结构所需字段。
5. 项目根哈希升级为 v2。编码按实体稳定 ID 排序，绑定每个活动 Document 的 ID、parent、kind、title、order key、active 状态哈希，以及每个活动 Block 的内容哈希。所有字段使用长度前缀二进制 framing，避免字符串拼接歧义。
6. 历史 v1 Commit 和快照保持可读，不批量重写。首次后续正文或结构提交自然产生 v2 根；恢复旧快照仍创建指向该快照原始根哈希的新 Commit。
7. 检查点恢复允许章节元数据变化。恢复事务先暂存当前活动章节的顺序键，再恢复快照中的标题、层级和顺序；当前多出的章节与 Block 被软归档，快照中存在但当前归档的实体被复活。发生结构变化的 Document revision 单调增加，不回退到快照 revision。
8. Tauri 单独授予 `allow-document-lifecycle`，只包含归档列表、重命名、排序和归档状态四个命令。WebView 不获得 SQL、任意结构批处理或物理删除能力。

## 桌面交互

- 每个活动章节提供上移、下移、重命名和归档按钮；首尾移动和最后一个章节归档在界面与 Host 两层拒绝。
- 所有结构操作前先刷新待保存 Block，防止结构 Commit 越过本地正文草稿。
- 结构命令返回权威完整工作区；页面替换 workspace、HEAD 和 revision，不在客户端猜测 Document revision。
- 归档章节显示在独立区域，恢复后重新选中；归档当前章节时自动选择剩余的稳定顺序首项。

## 测试要求

- Store 集成测试覆盖重命名、交换顺序、归档、恢复、陈旧 revision、Commit reason 与事务不变量；
- 检查点测试覆盖重命名、排序和归档之后恢复旧元数据，并验证 Document revision 单调增加、Block 正文重新可见；
- Host 测试验证结构变化会改变 v2 根哈希，而单纯重命名不会改变 Block 内容哈希；
- Tauri 测试覆盖 schema、permission、无项目、陈旧请求和四个生命周期命令；
- 浏览器回归覆盖新建、重命名、上移、归档、恢复、选中状态和布局无横向溢出。

## 后果

- 章节生命周期现在与正文编辑共享同一版本图、检查点和审计模型，不会出现“界面改了但版本未记录”的旁路状态；
- 软归档保留存储空间，后续需要显式、可审计的垃圾回收策略，不能把物理删除伪装成普通章节操作；
- 每次相邻排序会更新所有活动章节的顺序键和 revision。MVP 章节规模下成本可控；大规模树形文档应改为稀疏顺序键和局部重平衡；
- v1/v2 根可在同一 Commit DAG 中共存，根哈希的 codec 前缀决定语义，调用方不得仅凭哈希字符串推断版本。
